# Newspicel Homebrew tap

Homebrew packages for [sdr--](https://github.com/Newspicel/sdrminusminus), a modular
client–server software-defined radio.

```sh
brew tap newspicel/tap
```

## sdrminusminus (cask)

The desktop application: a native window over the receiver engine and the full interface.

```sh
brew install --cask sdrminusminus
```

Signed and notarized. The app updates itself, so Homebrew tracks the version but does not
drive the upgrade.

## sdrmm (formula)

The portable server. It listens on port `8080` and serves the same interface to any browser
on the network, which makes it the right choice for a Raspberry Pi or a home server.

```sh
brew install sdrmm
sdrmm --doctor
```

```sh
brew services start sdrmm
```

RTL-SDR, HackRF, RTL-TCP and SpyServer receivers are built in. Other hardware is reached
through SoapySDR modules, which install separately. SDRplay receivers additionally need the
vendor API from [sdrplay.com](https://www.sdrplay.com/downloads/), whose licence covers use
with genuine SDRplay hardware rather than redistribution.

Both packages install published release downloads rather than building from source, and are
regenerated by the release workflow in the main repository.
